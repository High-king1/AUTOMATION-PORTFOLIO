# Meme Coin Sniper Bot

## What it does
Detects new token launches and executes trades automatically via a connected Phantom (Solana) wallet — a technical demonstration of low-latency detection and on-chain execution.

## Tech stack
- Python
- Solana / Phantom wallet integration
- On-chain data monitoring

## How it works
```
New token launch detected → filter/validation logic → trade executed via Phantom wallet
```
