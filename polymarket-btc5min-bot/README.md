# Polymarket BTC 5-Min Prediction Bot

## What it does
Predicts BTC price direction on 5-minute windows for Polymarket-style prediction markets, then sends live signals to Telegram and Discord in real time.

## Tech stack
- Python
- Polymarket API (market/price data)
- Telegram Bot API
- Discord Bot API / Webhooks

## How it works
```
Live BTC price/market data → prediction logic → signal generated
                                          ↘ pushed to Telegram + Discord
```
